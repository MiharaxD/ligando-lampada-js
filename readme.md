# 💡 Lâmpada com JavaScript

Projetinho simples onde você clica num botão e a lâmpada liga e desliga. Só HTML, CSS e JS puro, sem framework nenhum.

## Como funciona

O JavaScript escuta o clique no botão e alterna uma classe (`ligada`) na lâmpada. O CSS cuida do resto: troca a imagem/cor e dá aquele brilhinho quando está acesa.

## Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)
